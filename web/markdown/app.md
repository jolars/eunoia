# Eunoia interactive app

The [interactive app](https://eunoia.bz/app/) fits area-proportional Euler and Venn diagrams in the browser. Enter set sizes and intersections, choose a shape, adjust fitting and display options, and export the result. The fitting engine runs locally through WebAssembly.

For a programmatic interface, see the [JavaScript quickstart](https://eunoia.bz/docs/quickstart/javascript/) and [JavaScript reference](https://eunoia.bz/docs/reference/javascript/).
